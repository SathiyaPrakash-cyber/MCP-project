How to generate an admin token

Run this in your Kali terminal inside the mcp-gateway directory:

export JWT_SECRET="mcp-gateway-dev-secret-change-in-prod-min32" source venv/bin/activate python scripts/gen_token.py --role admin

Paste the generated token in the input bar at the top of the page, then click Refresh.
